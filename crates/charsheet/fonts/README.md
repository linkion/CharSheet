# Fonts

These are Solbera's free imitations of the fonts used in the 5th Edition books,
with fixes by Ryrok, Ners and LUCASTUCIOUS, taken from
https://github.com/jonathonf/solbera-dnd-fonts. They are licensed under
Creative Commons Attribution-ShareAlike 4.0 (see `LICENSE`), separately from the
rest of CharSheet. The files are renamed but otherwise unmodified.

| File | Family | Used for |
|---|---|---|
| `ScalySans-*` | Scaly Sans Remake | Default UI text |
| `ScalySansCaps-*` | Scaly Sans Caps | Frame titles and small labels |
| `Bookinsanity-*` | Bookinsanity Remake | Notes and descriptions |
| `NodestoCapsCondensed-*` | Nodesto Caps Condensed | Character name and large numbers |
